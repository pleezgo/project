# Генерація документації

У проєкті використовується JSDoc для автоматичної генерації технічної документації з коментарів у коді.

## Що документується

Документація генерується для:
- `backend/src`
- `frontend/src`

У документацію потрапляють `.js` та `.jsx` файли, що містять JSDoc-коментарі.

Для відображення головної сторінки документації під час генерації використовується зміст `README.md`.

## Генерація

Перед генерацією документації потрібно переконатися що залежності встановлені.
Документація генерується з кореня репозиторію командою:

```bash
npm run docs
```

## Де знаходиться результат

Після успішної генерації HTML-документація буде доступна в папці:

```text
docs/generated
```

Головна сторінка документації:

```text
docs/generated/index.html
```

## Оновлення документації

Після змін у публічних інтерфейсах, бізнес-логіці або важливих модулях потрібно:
1. Оновити JSDoc-коментарі в коді.
2. Повторно запустити генерацію

```bash
npm run docs
```
